# زاد الذاكرين — النسخة المراجعة

تطبيق ويب عربي RTL يعمل كتطبيق PWA عند نشره على HTTPS.

## ما تم إصلاحه

- أزيلت قاعدة الـ600 السابقة لأنها احتوت نصوصًا مكررة ومراجع غير محددة وأدعية لا يمكن توثيقها.
- استبدلت بملف `verified-adhkar.json`؛ يحتوي الآن 267 نصًا من 132 بابًا في واجهة حصن المسلم، مع مصدر الباب ومعرّف النص.
- أضيفت خمس سمات: زمردي وذهبي، فاتح، أزرق ليلي، رملي ملكي، وردي هادئ.
- البحث الآن يشمل جميع الأقسام والنصوص والمصادر.
- حُفظ التقدم محليًا بمفاتيح خاصة بالتطبيق فقط؛ لم يعد المسح يزيل بيانات تطبيقات أخرى.
- أضيفت PWA: manifest، service worker، وأيقونة SVG للعمل دون إنترنت بعد الزيارة الأولى.

## تنبيه محتوى مهم

النصوص الحالية مأخوذة من أبواب واجهة حصن المسلم. أما «الفوائد» فلا تظهر إلا للحالات التي أُدخل لها فضل موثق؛ لا تضف فائدة إنشائية أو نصًا جديدًا على أنه مأثور حتى يراجعه مختص ويُكتب مصدره وتخريجه.

## التشغيل والنشر

ارفع كل محتويات هذا المجلد إلى استضافة HTTPS أو GitHub Pages. لا تشغّل التطبيق بفتح `index.html` مباشرة من مدير الملفات؛ لأن تحميل البيانات وService Worker يحتاجان خادمًا محليًا أو استضافة.

## الدفع

يمكن بيع التطبيق تقنيًا، لكن لا يُنصح بوضع الأذكار الأساسية خلف اشتراك أو حظر. النموذج الأنسب: المحتوى الأساسي مجانًا، مع دعم اختياري أو ميزات إضافية مدفوعة لا تمس الوصول إلى الذكر الموثق.
